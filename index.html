สาขาวิทยาการคอมพิวเตอร์

นักศึกษาสาขาวิชา วิทยาการคอมพิวเตอร์ มีความสนใจในการทำงานด้านเทคโนโลยีและการพัฒนาระบบ ชอบการวิเคราะห์ปัญหา ทำความเข้าใจกระบวนการทำงาน และค้นหาแนวทางในการพัฒนาระบบให้ตอบโจทย์การใช้งาน มีความสนใจในด้าน System Analysis, Data Analysis และ Web Development พร้อมเรียนรู้สิ่งใหม่ ๆ และนำความรู้จากการเรียนและการทำโปรเจกต์มาประยุกต์ใช้กับการทำงานจริง มีความตั้งใจที่จะพัฒนาตนเองและเรียนรู้จากประสบการณ์ การทำงานร่วมกับทีม

ระบบบริหารจัดการคลังวัสดุและครุภัณฑ์

System Design

ออกแบบระบบบริหารจัดการคลังวัสดุและครุภัณฑ์ที่มีประสิทธิภาพสำหรับหน่วยงานราชการ โดยทำการวิเคราะห์ Requirement และกระบวนการทำงาน เพื่อให้เข้าใจความต้องการของระบบ วิเคราะห์ Actors และ Functional Requirements เพื่อให้ครอบคลุมทุกผู้ใช้และฟีเจอร์ที่จำเป็น พร้อมเขียน Use Case Description โดยละเอียด ออกแบบ Activity Diagram เพื่อแสดงลำดับการทำงาน และวิเคราะห์ System Flow เพื่อประมาณการเวิร์คโฟลว์ของระบบ

Sales Data Analysis & Clustering

Data Analysis

วิเคราะห์และจัดกลุ่มข้อมูลการขายโดยใช้เทคนิค K-Means Clustering เพื่อแบ่งสินค้าออกเป็นกลุ่มตามราคา ส่วนลด และคะแนนประเมิน ทำการเตรียมข้อมูลด้วย Python และ Pandas พร้อมทำ Data Cleaning และ Feature Engineering เพื่อให้ข้อมูลมีคุณภาพสูง ใช้ Elbow Method เพื่อวิเคราะห์และกำหนดจำนวน Cluster ที่เหมาะสม สร้าง Visualization ด้วย Matplotlib เพื่อแสดงผลลัพธ์และ Export ไปสร้าง Dashboard ใน Power BI

Python Pandas Scikit-learn Matplotlib Power BI
